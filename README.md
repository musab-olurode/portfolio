# musab.dev

Portfolio and résumé of Mus'ab Olurode: a static Next.js 16 site, hosted on Cloudflare Workers.

- All copy lives in `src/content/profile.ts`; the home page and `/resume` both read from it.
- `npm run dev` to work locally, `npm test && npm run e2e` to check, and `npm run deploy` to ship.
- Deploy and domain setup: [docs/deploy.md](docs/deploy.md).
